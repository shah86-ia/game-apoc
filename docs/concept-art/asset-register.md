## Версионирование новых концепт-артов

1. Каждый **новый** концепт сохранять в своей тематической папке с суффиксом `-v001.png`. Следующая правка — `-v002.png`, и так далее.
2. Для одного изображения/серии хранить единый смысловой идентификатор, например `level-01-arrival-overview-v001.png` и `level-01-arrival-overview-v002.png`.
3. В этом реестре фиксировать для серии последнюю утверждённую рабочую версию, статус и описание изменений.
4. Уже существующие файлы без суффиксов считаются **исходной точкой (baseline)**. Не переименовывать их задним числом и не создавать новые копии без запроса.
5. Новые архивы формировать **только из новых изображений текущей поставки**, не добавляя туда автоматически прежние концепты и старые версии.
6. Не считать изображение утверждённым каноном лишь потому, что оно присутствует в репозитории.
7. Концепты не являются готовыми игровыми спрайтами.

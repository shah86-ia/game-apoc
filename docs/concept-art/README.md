# Общие визуальные материалы

`maps/` — глобальные схемы мира и карта-блокнот; это не самостоятельные игровые уровни.

`story/` — визуальные исследования катастрофы, не утверждающие её детальную хронологию.

Рабочие концепты игровых мест располагаются в `levels/<location>/concept-art/`, персонажей — в `characters/<character>/concept-art/`, переиспользуемых объектов — в `objects/`.

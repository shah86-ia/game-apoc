# Объекты и пропсы

Переиспользуемые объекты мира: двери, мебель, транспорт, оборудование, контейнеры и др. Их игровые ресурсы хранятся отдельно от уровней и персонажей.

## Концепт-арты
- `concept-art/level-01-objects-reference.png` — текущий лист объектов первого уровня; содержит также изображения людей как референсы, но игровые персонажи относятся к `characters/`. Это **не готовый спрайт-атлас**.

Новые варианты именовать с суффиксами версий (`-v001`, `-v002`); удалённые изображения из прежних архивов не возвращать.

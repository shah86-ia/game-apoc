# Дорожный TileSet (`road_tileset.tres`)

Изометрическая сетка 64×32, раскладка `Diamond Down`, фильтр Nearest.

## Откуда взят рисунок
Лист `reference/road-tileset-sheet.png` — презентация тайлсета (1536×1024, подписи, тёмный фон).
Использовать его напрямую как атлас нельзя: тайлы на нём разного размера (≈140×70 – 230×110 px),
это толстые плиты с боковой гранью, и в одной плите уже вся ширина дороги вместе с тротуаром.
Поэтому с листа взят только **материал**:
- асфальт — чистые кусочки (без разметки и бордюра) собраны в бесшовную текстуру `asphalt-v001.png` (512×256);
- цвета бордюра и краски разметки.

Сами тайлы нарисованы скриптом `tools/road/build_road_tiles.py` точно под сетку 64×32.

## Файлы
| Файл | Что это |
|---|---|
| `road_tileset.tres` | TileSet: источник 0 «Дорога», источник 1 «Разметка», Terrain «Асфальт» |
| `road-tiles-v001.png` | атлас дороги 1024×288 |
| `road-markings-v001.png` | атлас разметки 256×32 |
| `asphalt-v001.png` | бесшовная текстура асфальта |
| `road_asphalt.gdshader`, `road_asphalt_material.tres` | шейдер слоя дороги |
| `reference/road-tileset-sheet.png` | исходный лист-референс (не используется в игре) |

## Как устроен асфальт
В атласе пиксели асфальта помечены альфой 254. Материал `road_asphalt_material.tres` на слое дороги
заменяет их текстурой `asphalt-v001.png`, уложенной в **мировых координатах**. Поэтому рисунок асфальта
не повторяется в каждой клетке и между тайлами нет швов. Бордюр, лоток у бордюра и пустые места берутся
из тайла как есть. Слой дороги без этого материала покажет асфальт, но с заметными повторами.

## Атлас дороги
- **Ряд 0** — 15 тайлов автотайлинга (Terrain «Асфальт», режим Match Corners). Номер столбца — какие углы
  клетки покрыты асфальтом: 1 — верхний, 2 — правый, 4 — нижний, 8 — левый (15 — сплошной асфальт).
  Край дороги проходит через центры клеток.
- **Ряды 1–6 (до середины ряда 6)** — тайлы больших скруглений: внутренние углы перекрёстков (радиус 6 клеток ≈ 3,7 м) и
  внешние углы поворотов (радиус 3 клетки ≈ 1,8 м), во всех четырёх поворотах.
- **Остаток ряда 6 и ряды 7–8** — особые тайлы уровня 01: плавные въезд и выезд автобусного кармана.

## Разметка (источник 1)
| Тайл | Что |
|---|---|
| (0, 0) | осевой пунктир вдоль оси x сетки (на экране вправо-вниз) |
| (1, 0) | осевой пунктир вдоль оси y (на экране вправо-вверх) |
| (2, 0) | полоса «зебры» вдоль оси x |
| (3, 0) | полоса «зебры» вдоль оси y |

Пунктир ставится по 3 клетки через 5, полосы зебры — через клетку.

## Как рисовать и править дороги в Godot
1. Выделите слой `Ground/Road` → внизу панель **TileMap** → вкладка **Terrains** → «Асфальт».
2. Рисуйте кистью: края, повороты и перекрёстки подбираются сами (со скруглением в полклетки).
3. Большие скругления углов — вкладка **Tiles**, ряды 1–6 атласа: ставятся вручную по клеткам, как в готовых
   перекрёстках уровня (удобно скопировать готовый угол: выделение → Ctrl+C → Ctrl+V).
4. Разметка — слой `Ground/RoadMarkings`, вкладка **Tiles**, источник «Разметка».
5. Стереть — правая кнопка мыши.

## Пересборка
```
python tools/road/build_road_tiles.py            # картинки
godot --headless --path . --import
godot --headless --path . -s tools/road/build_road_resources.gd   # TileSet
```
Флаги `--level` (Python) и `-- level` (Godot) дополнительно пересобирают дороги `Level01.tscn` —
**ручные правки уровня и расставленные объекты при этом пропадут.**

## Чего не хватает (на будущее)
- Высоты бордюра (видимой боковой грани): сейчас бордюр плоский.
- Деталей асфальта поверх текстуры: люки, решётки ливнёвки, трещины, заплатки, ямы
  (на листе-референсе есть в ряду «Детали» — их можно сделать отдельными спрайтами-наклейками).
- Разметки: стоп-линий, сплошных линий, краевых линий, разметки автобусного кармана.
- Стыков дороги с тротуаром, обочиной и грунтом: по заданию уровня пока только дорога.
- Диагональных дорог: дороги идут только по осям сетки.

# Локация — бывший радиотехнический завод

**Статус:** географическая и историческая роль утверждена; игровой уровень не спроектирован.

Бывшее советское радиотехническое предприятие в 1990-е разделилось на небольшие действующие фирмы и мастерские. Территория не должна выглядеть полностью заброшенной до катастрофы. Исторически рядом располагалось убежище гражданской обороны; прямой служебный путь к его единственному входу завален.

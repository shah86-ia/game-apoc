# Игровые локации (`levels/`)

Каждая игровая локация, включая бункер, завод, улицы и интерьеры, имеет отдельную папку. В ней находятся `README.md` с игровыми требованиями и `concept-art/` с референсами; будущие сцены Godot, данные навигации и триггеров также относятся к соответствующему уровню.

## Локации
- [Возвращение домой — стартовый квартал](level-01-arrival/README.md)
- [Убежище](bunker/README.md)
- [Бывший радиотехнический завод](factory/README.md)
- [АЗС — только рабочий концепт, игровая локация не утверждена](gas-station/README.md)

Номер `01` пока присвоен только вступительной сцене. Остальные папки названы по локации: последовательность их посещения не утверждена.

## Границы ответственности
- `levels/` — игровые места, их карты, сценарии и уникальное окружение.
- [`characters/`](../characters/README.md) — герои и NPC, визуал и анимации.
- [`objects/`](../objects/README.md) — повторно используемые предметы, мебель, двери, транспорт и оборудование.
- [`docs/concept-art/`](../docs/concept-art/README.md) — общие карты мира и визуальные исследования сюжета.

Рабочие изображения **не утверждают** детали географии или лора. GitHub содержит пользовательский актуальный набор PNG и описания. Прежние архивы не использовать для восстановления удалённых изображений. Новые изображения версионировать согласно `docs/concept-art/asset-register.md`.

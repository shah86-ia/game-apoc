# Локация — убежище

**Статус:** утверждённые исходные условия; детальная игровая планировка не утверждена. Номер в последовательности уровней не назначен.

## Утверждено
- Небольшое бывшее советское убежище гражданской обороны, исторически связанное с радиотехническим заводом.
- В 1990-х официально выведено из эксплуатации; переносимое ценное оборудование вывезено официально, не разграблено.
- Один-единственный основной вход; второго, тайного или аварийного входа нет.
- К этому входу подходили два маршрута: прямая дорога от завода завалена после консервации; другой путь проходим.
- Герой получает найденные дома дедовы неучтённые дубликаты ключей и документы.
- Первое посещение — до полной катастрофы, из любопытства: открыть вход, осмотреть помещение с фонарём, увидеть настенный план и одну деформированную заклинившую внутреннюю дверь; затем вернуться домой.
- На первом посещении доступно только входное помещение; других внутренних дверей не добавлять без согласования.

## Не утверждено
Точные размеры, план комнат, причина деформации двери, механика ремонта, координаты на глобальной карте.

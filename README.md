# Постапокалипсис

Игра на Godot 4.

## Как открыть
1. Установите [Godot 4.7](https://godotengine.org/download) (проект проверен на 4.7.2, рендерер Compatibility).
2. В менеджере проектов нажмите **Import** и выберите `project.godot`.

## Текущий прототип
Главная сцена — `scenes/test/iso_movement_test.tscn`: изометрическая сетка, главный герой (Idle, ходьба и бег в 8 направлениях), камера и тестовые препятствия (`World/Obstacles`).
Запуск — **F5**. Управление — **WASD** (работает и на русской раскладке), **Shift** (левый или правый) + WASD — бег.

- Скорость ходьбы: узел `World/Player` → инспектор → `Move Speed` (120 px/s).
- Бег: там же `Run Speed Multiplier` (1.68 → ≈ 202 px/s) и `Speed Change Rate` — плавность перехода ходьба ↔ бег (300 px/s², ≈ 0,27 с).
- FPS анимаций: двойной клик по `characters/protagonist/animations/protagonist_frames.tres` → панель SpriteFrames → выбрать анимацию → поле FPS. Сейчас `walk_*` — 8, `run_*` — 10,5.
- Масштаб героя: узел `World/Player/AnimatedSprite2D` → `Node2D → Transform → Scale` (сейчас 0.5 = рост 112 px).
- Плавность камеры: узел `World/Player/Camera2D` → `Position Smoothing → Speed` (меньше — плавнее).
- Препятствия (`World/Obstacles`) — обычные узлы сцены, без скриптов: `StaticBody2D` → `CollisionShape2D` (ромб на земле, точки тянутся мышкой) и узлы-клетки `Cell` с гранями `Polygon2D` (`Top`, `FaceLeft`, `FaceRight`) и контуром `Line2D`. Позиция блока — северный угол его ромба, ставится в вершину сетки: клетка (x, y) → ((x − y)·32, (x + y)·16). Новый блок — дублировать существующий (Ctrl+D) и передвинуть.
- Герой и препятствия лежат в узле `World` с Y-sort: кто ниже на экране, тот рисуется поверх.

### Прозрачность объектов, закрывающих героя
Узел `OcclusionManager` (`scripts/systems/occlusion_manager.gd`) делает полупрозрачными объекты из группы **`occludable`**, когда их видимые части, которые рисуются позже героя (Y-sort), закрывают **заметную долю силуэта героя** — по умолчанию не меньше 25 % его непрозрачных пикселей. Считаются реальные пиксели картинок и формы полигонов. Рядом с объектом или перед ним прозрачность не включается. Коллизии не меняются: прозрачность ставится через `modulate` у визуальных дочерних узлов объекта.

- Общие параметры — в инспекторе узла `OcclusionManager`: `Occluded Alpha` (0.35), `Fade Time` (0.2 с), `Min Coverage` (0.25 — доля закрытого героя для включения; выключается при доле вдвое меньше), `Release Delay` (0.1 с), `Sample Step` (3 — точность подсчёта).
- Тестовый объект — `World/Obstacles/TallPillar` (коллизия только у основания, изображение высокое).
- Автобусная остановка — `World/Obstacles/BusStop` (сцена `objects/bus-stop/BusStop.tscn`, подробности в `objects/bus-stop/README.md`).

**Как подключить новое дерево, забор или здание:**
1. Сделайте объект как обычно: `StaticBody2D` (с `CollisionShape2D` у основания) и визуальные дочерние узлы — `Sprite2D`, `AnimatedSprite2D`, `Polygon2D` или контейнер `Node2D` с ними. Положите его в `World/Obstacles` (или другой узел с Y-sort).
2. Выделите объект → вкладка **Узел → Группы** → добавьте группу `occludable`.
3. На сцене должен быть один узел `OcclusionManager` с заполненным полем `Target Sprite` (спрайт героя). В новой сцене — скопируйте его из тестовой.
4. При необходимости переопределите параметры для этого объекта: **Инспектор → Metadata → Add Metadata**: `occlusion_alpha` (float), `occlusion_fade_time` (float), `occlusion_min_coverage` (float), `occlusion_enabled` (bool).
5. Длинные объекты (забор, стена), которые сортируются по частям, — разбейте на дочерние `Node2D` по клеткам, как `LongBlock`: прозрачность включится, когда герой зайдёт за любую часть, а погаснет весь объект целиком.
- Размер ромба сетки: узел `IsoGrid` → `Tile Size` (временно 64×32).

## Структура
```
scenes/          — сцены (.tscn)
scenes/test/     — тестовые сцены прототипа
scripts/         — скрипты GDScript (.gd)
scripts/player/  — скрипты персонажа (player.gd)
characters/<имя>/animations/ — игровые анимации персонажа и SpriteFrames
scripts/test/    — вспомогательные скрипты тестовых сцен
scripts/systems/ — общие системы (прозрачность объектов)
assets/sprites/  — графика
assets/audio/    — звуки и музыка
assets/fonts/    — шрифты
```

## Git
- Папка `.godot/` не коммитится — Godot пересоздаёт её сам.
- Файлы `*.import` коммитятся (в них настройки импорта ассетов).
- Коммитим небольшими шагами с понятным описанием, например:
  `Добавлен игрок: движение и анимация бега`.
